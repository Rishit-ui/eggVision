## Open Images V7 – Egg (Food) class licensing details

Open Images V7 provides **two distinct licences**:

| Asset type | Licence | Notes |
|------------|---------|-------|
| **Images** | **Creative Commons Attribution 2.0 (CC BY 2.0)** | Each image includes its own attribution metadata (author, original URL, landing page, etc.). The licence requires you to retain the original attribution when redistributing or creating derivative works. |
| **Annotations (bounding‑box CSVs, segmentation metadata)** | **Creative Commons Attribution 4.0 (CC BY 4.0)** | Annotation files are released under CC BY 4.0 and must be cited with a link to the Open Images V7 dataset. |

### Required per‑image attribution fields (available in the official image‑info CSVs)
For every image we must retain the following fields when storing or redistributing the image:

- `ImageID` – the Open Images identifier (used as the filename).
- `OriginalURL` – direct URL to the original image.
- `OriginalLandingURL` – web page where the image is presented.
- `Author` – name of the photographer/creator.
- `AuthorProfileURL` – link to the author’s profile (if provided).
- `Title` – title/description supplied by the author.
- `License` – licence string (e.g. `CC BY 2.0`).
- `Subset` – dataset split (`train`, `validation`, or `test`).
- `Version` – dataset version (`v7`).

When an image is downloaded we store a small side‑car JSON file alongside the JPEG containing the above fields. This guarantees we can reconstruct the full attribution later.

> **Do not claim** that *all* images are CC BY 4.0. Images retain their **CC BY 2.0** licence; only the annotation files are CC BY 4.0.
